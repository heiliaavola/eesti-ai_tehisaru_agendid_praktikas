# Töötoa harjutusprojekt

See on eesti.ai töötoa „Tehisaru agendid praktikas“ harjutusprojekt. Kasutaja võib olla terminalis esimest korda. Projekt töötab GitHub Codespacesi pilvekeskkonnas.

## Kuidas töötada

- Vasta eesti keeles, lühidalt ja lihtsate sõnadega.
- Enne suuremat muudatust kirjelda plaan ja oota kasutaja kinnitust.
- Enne iga käsu käivitamist selgita ühe lausega, mida käsk teeb.
- Tee väikesed sammud. Pärast iga sammu kontrolli tulemust: käivita kood või ava leht.
- Kui teed veebilehe, kirjuta see ühte faili `index.html` ilma välisteekideta, kui kasutaja ei palu teisiti.
- Ütle ausalt, mida sa ei kontrollinud või mis jäi pooleli.

## Piirangud

- Kasuta ainult näidis- või väljamõeldud andmeid. Kui kasutaja kirjutab isikuandmeid, paroole või tööalast konfidentsiaalset infot, hoiata teda.
- Ära paigalda pakette ega laadi faile alla ilma kasutaja loata.
- Ära kustuta faile ega käivita käsku `git push`.
- Muuda ainult selle kausta faile.

## Eelvaade

Veebilehe vaatamiseks käivita `python3 -m http.server 8000`. Codespaces avab eelvaate ise, muidu ava vahekaart PORTS ja port 8000.
